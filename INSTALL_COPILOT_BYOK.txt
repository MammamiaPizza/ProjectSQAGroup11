AI2 GitHub Copilot CLI + KKU DeepSeek installation

This overlay is intended for the existing Optimized v3 project.
It does NOT replace Experiment/automation/ai_runner.py used by ChatGPT workers.
It creates a separate Experiment/automation/ai2_runner.py.

AI2 configuration:
- GitHub Copilot CLI 1.0.88
- BYOK provider: KKU IntelSphere OpenAI-compatible endpoint
- Model: deepseek-v4-pro
- Tools: disabled by empty/sentinel allowlist
- Built-in MCP: disabled
- Custom instructions: disabled
- Clean cwd: /tmp/sqa-copilot-clean/<worker>
- Same optimized P01-P04 templates already under AI2_GitHubCopilot/Prompt
- Results: AI2_GitHubCopilot/{Prompt,Result,TestCode}/<case>/run-final-opt
- Evaluation: Experiment/evaluations/<case>/copilot-run-final-opt-final
- Copilot source-validation workspaces use *-copilot and do not race AI1 *-ai workspaces.
- D4J slot namespace uses run-final-opt, so AI1 and AI2 share the same heavy-job semaphore.

Before pilot:
  copilot --version
  copilot --help | grep -A2 -B2 usage-output-file
  python3 -m py_compile Experiment/automation/ai2_runner.py

Pilot:
  ./Experiment/automation/pilot_copilot.sh

After pilot, inspect:
  python3 Experiment/automation/token_report_copilot.py

Start real shared queue workers:
  D4J_SLOTS=3 ./Experiment/automation/start_copilot_worker.sh C1
  D4J_SLOTS=3 ./Experiment/automation/start_copilot_worker.sh C2

Status:
  ./Experiment/automation/status_copilot_workers.sh

Stop:
  ./Experiment/automation/stop_copilot_worker.sh C1

IMPORTANT: API keys are prompted silently and are not written into project files.
