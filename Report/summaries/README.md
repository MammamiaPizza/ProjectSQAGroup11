# Method Summaries

โฟลเดอร์นี้เก็บผลสรุปสำหรับคนอ่าน โดยสรุปจากผลการทดลองของแต่ละวิธี

แต่ละ summary ควรระบุอย่างน้อย:

- จำนวนกรณีทดลองทั้งหมด
- จำนวนกรณีที่ประเมินผลได้จริง
- จำนวนกรณีที่ตรวจพบ fault
- Fault detection rate
- Line coverage
- Condition/branch coverage
- จำนวน test ที่สร้าง ถ้ามี
- Generation time ถ้ามีและเปรียบเทียบได้
- ข้อจำกัดหรือเงื่อนไขของผล
