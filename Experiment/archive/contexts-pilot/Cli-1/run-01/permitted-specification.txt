Apache Commons CLI issue CLI-13 is described as "CommandLine.getOptionValue() behaves contrary to docs" in the Apache Commons CLI release notes. Source: https://github.com/apache/commons-cli/blob/master/RELEASE-NOTES.txt . The Javadoc in the supplied buggy CommandLine.java says getOptionValue(String) returns the argument value if an option is set and has an argument; otherwise null. Use the supplied Javadoc for the other overloads. Do not infer behavior from the buggy method body.
