# สรุปผลการทดลอง

โฟลเดอร์นี้ใช้เก็บไฟล์สรุปผลที่นำมาจากผลการทดลองจริง

รอบสุดท้ายที่ใช้:
- ChatGPT: `run-final-opt`
- GitHub Copilot: `copilot-final-v2`

ไฟล์ที่จะจัดทำเพิ่มเติม:
- `final_summary.md` สรุปผลรวม
- `final_case_results.csv` ผลรายเคส
- `recovery_summary.md` สรุปเคสที่มีการกู้ผลหรือแก้ปัญหาระหว่างทดลอง
- `projects/` สรุปผลแยกตามโปรเจกต์

ข้อมูลดิบยังเก็บไว้ใน:
- `AI1_ChatGPT/`
- `AI2_GitHubCopilot/`
- `Experiment/evaluations/`
